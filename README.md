# Olist Brazilian E-Commerce Data Dashboard

Interactive data dashboard analyzing ~100,000 real e-commerce orders from Brazil's largest marketplace (2016-2018).

## Live Demo

**[View Dashboard](https://carefreemoon1025.github.io/olist-dashboard/)**

## Key Findings

- **Total GMV**: R$ 13.5M across 96K delivered orders
- **Delivery speed is the #1 driver of satisfaction**: orders delivered within 10 days avg 4.4 stars, dropping to 2.2 stars for 30+ day deliveries (-50%)
- **3% repeat purchase rate** — Olist is a single-purchase platform
- **SP state accounts for 38% of GMV**, top 3 states = 63%
- **Credit card installments** directly increase order value (10-installment avg: R$ 500+)

## Tech Stack

- **Data Analysis**: Python (pandas) + SQL (SQLite)
- **BI Dashboard**: Power BI (star schema, DAX measures, 4-page interactive report)
- **Web Dashboard**: Chart.js + HTML/CSS

## About This Project

This is a portfolio project demonstrating end-to-end data analysis skills — from raw CSV files to interactive dashboards. Data source: [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) on Kaggle.
