# 面试演示脚本

## 0. 项目开场

> 这是一个 Olist 电商经营分析 Copilot。我把传统的数据分析流程、订单延迟预测和受控式大模型交互放在同一个可复现的 Streamlit 应用中。

## 1. 经营总览

展示订单量、支付金额、客单价、延迟率和平均评价。

说明：

> 指标统一由指标层维护，避免不同页面出现不同口径。

## 2. 履约分析

展示正常送达与延迟送达的评价差异。

说明：

> 这里的关系是观察性分析，不能直接解释成因果关系。

## 3. 机器学习

展示 Logistic Regression 的评估结果。

说明：

> 训练特征只使用订单早期可以获得的信息，实际送达时间和评价分数没有进入特征，避免数据泄漏。

## 4. AI 助手

输入：

> 哪些地区的订单延迟率最高？

依次展示：

1. 结构化意图；
2. 白名单指标和维度；
3. 分析结果表；
4. 图表；
5. AI 生成的核心发现和建议。

说明：

> 大模型不直接执行自由 SQL。它只负责识别意图和解释真实计算结果，数据库查询由受控分析工具完成。

## 5. A/B 测试

输入 A/B 两组转化人数和样本数，展示转化率、提升幅度和 p-value。

说明：

> Olist 是观察性数据，不具备随机实验分组，所以 A/B 页面使用独立参数演示统计检验，没有把观察性差异包装成实验结论。
